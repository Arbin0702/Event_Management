# Project Summary

## Project Purpose

The Event Management System is a web-based application designed to help users create, organize, and manage events efficiently. 

The system allows event organizers to schedule events, manage attendees, and track event details in one centralized platform. It simplifies the process of event planning and improves communication between organizers and participants.

## User Roles

1. Admin
   - Manages user accounts
   - Approves or removes events
   - Monitors overall system activity
   - Ensures platform security and data integrity

2. Event Organizer
   - Creates and edits events
   - Sets event date, time, and location
   - Manages attendee registrations
   - Views event statistics and participant list

## Core Workflow

1. User registers and logs into the system.
2. Event Organizer creates a new event.
3. Organizer enters event details (title, date, location, description).
4. Participants register for the event.
5. Organizer monitors registrations and updates event information if needed.
6. Admin oversees system activity and ensures proper management.
